
# GrowDesign AI Toolkit 🎨

A free, open-source caption idea generator for designers,
creators, and social media users.

🌐 **Live Website:**
https://ramzanshaikhjakir-cloud.github.io/growdesign-ai-toolkit/

## Features

- Generate ready-made caption ideas
- Five categories: Design, Business, Fashion, Travel, Lifestyle
- Copy captions with one click
- Mobile-friendly interface
- No account or API key required

## How to Use

1. Visit the live website.
2. Select your preferred category.
3. Click "Generate Caption".
4. Click "Copy Caption" to copy the result.

## How It Works

This project uses HTML, CSS, and JavaScript.

Captions are randomly selected from a collection of
prewritten examples. It does not currently use an AI model.

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start generating caption ideas.
